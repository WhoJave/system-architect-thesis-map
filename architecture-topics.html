15. 母题一：RAG

需要掌握

  • 异构文档解析与清洗
  • Chunk 切分
  • Embedding / 向量化
  • 向量检索、关键词检索、混合检索
  • Top-K
  • Rerank
  • 上下文窗口控制
  • 引用与可追溯
  • 幻觉抑制
  • 权限隔离
  • 数据更新

消费金融落地点

  • 产品制度
  • 运营规范
  • 客服知识
  • 流程手册
  • 内部制度问答

16. 母题二：Agent

需要掌握

  • 任务规划
  • ReAct / Plan-Execute
  • 工具注册与 Tool Calling
  • 参数 Schema
  • 权限控制
  • 超时
  • 重试
  • 幂等
  • 状态管理
  • 短期/长期记忆
  • Human-in-the-loop
  • 审计
  • 防止死循环

消费金融落地点

建议写低风险内部流程，不让 Agent 自动做核心授信决策。

例如：

  • 客服辅助
  • 运营工单
  • 内部知识查询
  • 报表生成
  • 流程辅助

17. 母题三：分布式缓存

需要掌握

  • 缓存客户端
  • Redis 集群
  • 数据库权威源
  • Cache-Aside
  • Key 设计
  • TTL
  • 淘汰
  • 穿透
  • 击穿
  • 雪崩
  • 热 Key
  • 大 Key
  • 缓存一致性
  • 高可用
  • 降级

消费金融适合缓存

  • 产品配置
  • 公共字典
  • 渠道参数
  • 低频变化规则

不应只依赖缓存判断：

  • 放款最终状态
  • 借据核心状态
  • 核心账务金额

18. 母题四：消息队列

需要掌握

  • Producer
  • Broker
  • Topic/Queue
  • Consumer
  • 异步处理
  • 应用解耦
  • 流量削峰
  • 路由
  • 可靠投递
  • ACK
  • 重试

  • 重复消费
  • 幂等
  • 顺序
  • 积压

消费金融落地点

适合异步：

  • 消息通知
  • 贷后任务

核心交易不要“为了 MQ 而 MQ”。

21. 母题七：分布式一致性

需要掌握

  • 一致性为什么出现问题
  • 网络超时
  • 服务故障
  • 消息重复
  • 并发
  • 强一致
  • 最终一致
  • CAP / BASE
  • 本地事务
  • TCC
  • Saga
  • 事务消息
  • Outbox
  • 幂等
  • 重试
  • 补偿
  • 对账
  • 人工兜底

消费金融核心判断

先问：

哪些数据必须立即一致？

例如核心资金/账务场景要求更严格。

再问：

哪些数据可以最终一致？

例如部分通知、分析、异步状态传播。
