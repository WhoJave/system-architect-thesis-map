# System Architect Thesis Map

系统架构设计师论文备考知识地图（消费金融脱敏项目版）。

## 内容

- 论文评分与写作结构
- 审题与项目底座
- 全局架构师视角
- 摘要 / 背景 / 理论 / 核心实践 / 结尾
- RAG / Agent / 分布式缓存 / 消息队列 / 弹性伸缩 / DDD / 分布式一致性 / 微服务
- Work 训练任务与考场模拟
- Mermaid 思维导图

## 本地预览

直接使用任意静态 HTTP Server 打开根目录即可，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## GitHub Pages

仓库为纯静态站点，可在 GitHub Pages 中选择 `main` 分支根目录进行发布。
